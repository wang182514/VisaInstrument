# R&S SMU200A — 项目 SCPI 速查手册

> 所有命令按功能分类。SMU200A 使用类似 SCPI 的指令集，多数命令可省略冒号前缀。
> 带 `[W]` 为只写命令，带 `[Q]` 为只读查询。

---

## 一、系统控制

| 命令      | 方向  | 说明               |
| ------- |:---:| ---------------- |
| `*CLS`  | W   | 清空状态寄存器和错误队列     |
| `*IDN?` | Q   | 查询仪器标识字符串        |
| `*OPC?` | Q   | 等待当前操作完成后返回 `+1` |

---

## 二、CW 模式（点频输出）

信号源最常用模式——输出单一频率的连续波。

| 命令                | 方向  | 说明                         |
| ----------------- |:---:| -------------------------- |
| `FREQ <value>MHz` | W   | 设置输出频率（支持 MHz / GHz / KHz） |
| `POW <value>dBm`  | W   | 设置输出功率                     |
| `:FREQ:MODE CW`   | W   | 切换到 CW（连续波）模式              |
| `OUTP ON`         | W   | 开启 RF 输出                   |
| `OUTP OFF`        | W   | 关闭 RF 输出                   |

---

## 三、扫频模式

用于平坦度测试等需要信号源自动扫频的场景。

| 命令                     | 方向  | 说明         |
| ---------------------- |:---:| ---------- |
| `FREQ:STAR <value>GHz` | W   | 扫频起始频率     |
| `FREQ:STOP <value>GHz` | W   | 扫频终止频率     |
| `SWE:STEP <value>KHz`  | W   | 频率步进       |
| `SWE:DWEL <value>ms`   | W   | 每步驻留时间     |
| `SWE:SPAC LIN`         | W   | 线性扫频       |
| `SWE:MODE AUTO`        | W   | 自动扫频模式     |
| `:FREQ:MODE SWE`       | W   | 切换到扫频模式    |
| `POW <value>dBm`       | W   | 扫频时的固定输出功率 |

---

## 四、RF 输出控制

| 命令         | 方向  | 说明       |
| ---------- |:---:| -------- |
| `OUTP ON`  | W   | 开启 RF 输出 |
| `OUTP OFF` | W   | 关闭 RF 输出 |

> 注意：`OUTP` 不带冒号。

---

## 五、调制控制

SMU200A 配有基带单元，可输出调制信号。ACPR 测试需要开启调制。

| 命令                     | 方向  | 说明         |
| ---------------------- |:---:| ---------- |
| `:MOD:STAT ON`         | W   | 开启所有调制     |
| `:MOD:STAT OFF`        | W   | 关闭所有调制     |
| `:SOUR:BB:DM:STAT ON`  | W   | 开启基带数字调制输出 |
| `:SOUR:BB:DM:STAT OFF` | W   | 关闭基带数字调制输出 |

### 5.1 调制参数设置（数字调制）

开启调制前需先配置调制参数，命令均可查询（后缀 `?`）：

| 命令                                             | 方向  | 说明                                                     |
| ---------------------------------------------- |:---:| ------------------------------------------------------ |
| `:SOURce:BB:DM:SRAT <value>`                   | W/Q | 设置/查询符号速率 (symbol rate)                                 |
| `:SOURce:BB:DM:FORMat <value>`                 | W/Q | 设置/查询调制类型，value = QPSK / PSK8 / QPSK45 / QEDG / P4QP    |
| `:SOURce:BB:DM:FILTer:TYPE RCOSine`            | W/Q | 设置/查询滤波器类型，RCOSine = 升余弦滤波器                             |
| `:SOURce:BB:DM:FILTer:PARameter:RCOSine <value>` | W/Q | 设置/查询滚降系数 (roll-off factor)，典型值 0.25                     |

> **注意事项**：ACPR 测量需调制信号（先设调制参数、开 BB 输出、再开调制）；饱和功率（Psat）测量需纯 CW（先关调制、再关 BB 输出）。
