# 直流电源 — SCPI 速查手册

> 覆盖两款 GWINSTEK 固纬直流电源：**PSW-8027（单通道，TCP/IP SCPI）** 与 **GPP-4323（四通道，USB 虚拟串口）**。
> 所有命令按功能分类，格式为 `:SUBSYS:CMD <参数>`（写）或 `:SUBSYS:CMD?`（查询）。
> 带 `[W]` 为只写命令，带 `[Q]` 为只读查询。
> 指令以 `\n` (LF) 结尾；GPP-4323 设置类指令（电压/电流）不带冒号前缀。

---

## 一、连接方式

### 1.1 单通道电源 PSW-8027（TCP/IP）

| 项目 | 值 |
| --- | --- |
| 物理连接 | 网线 TCP/IP，端口 **2268** |
| 指令结尾 | `\n` (LF) |
| 超时建议 | 1 s |

**建立连接**：

1. 网线连接 PC 与电源 LAN 口，PC 与电源配置同一网段；
2. 建立 TCP 连接（`IP:2268`）；
3. 发送 `*IDN?` 验证连接，返回设备标识字符串即成功。

### 1.2 多通道电源 GPP-4323（USB 虚拟串口）

| 项目 | 值 |
| --- | --- |
| 物理连接 | USB → 虚拟串口 COMx |
| 波特率 | 9600 |
| 数据位 / 校验 / 停止位 | 8 / None / 1（8N1） |
| 指令结尾 | `\n` (LF) |

**建立连接**：

1. USB 连接 PC 与电源，确认系统枚举出虚拟串口（如 COM11）；
2. 打开串口：`9600, 8N1`；
3. 发送 `*IDN?` 验证连接。

> 一台 GPP-4323 含 4 个通道，**所有通道共享同一串口**，指令中用通道号后缀区分目标通道，**无需切换通道**。

---

## 二、系统控制

| 命令 | 方向 | 说明 |
| --- |:---:| --- |
| `*IDN?` | Q | 查询仪器标识字符串（建立连接后首先验证） |
| `:SYST:ERR?` | Q | 查询错误队列（GPP-4323 支持，正常返回 `0,"No error"`） |

---

## 三、单通道电源 SCPI（PSW-8027，TCP :2268）

### 3.1 输出控制

| 命令 | 方向 | 说明 |
| --- |:---:| --- |
| `:OUTP 1` | W | 开启输出 |
| `:OUTP 0` | W | 关闭输出 |
| `:OUTP?` | Q | 查询输出状态（返回 `1` = 开，`0` = 关） |

### 3.2 电压 / 电流设置

| 命令 | 方向 | 说明 |
| --- |:---:| --- |
| `:SOUR:VOLT <value>` | W | 设置输出电压（V） |
| `:SOUR:CURR <value>` | W | 设置输出限流（A） |

### 3.3 测量

| 命令 | 方向 | 说明 |
| --- |:---:| --- |
| `:MEAS:VOLT?` | Q | 读取实际输出电压（V） |
| `:MEAS:CURR?` | Q | 读取实际输出电流（A） |

---

## 四、多通道电源 SCPI（GPP-4323，USB 串口）

**指令规则**：`{ch}` 为通道号（1~4），直接以通道号后缀区分目标通道；电压/电流设置类指令**无冒号前缀**，其余带冒号。

### 4.1 输出控制

| 命令 | 方向 | 说明 |
| --- |:---:| --- |
| `:OUTP{ch} On` | W | 开启指定通道输出（如 `:OUTP1 On`） |
| `:OUTP{ch} Off` | W | 关闭指定通道输出（如 `:OUTP1 Off`） |
| `:OUTP{ch}?` | Q | 查询指定通道输出状态（返回 `ON` 或 `1` = 开） |

### 4.2 电压 / 电流设置（无冒号前缀）

| 命令 | 方向 | 说明 |
| --- |:---:| --- |
| `VOLT{ch} <value>` | W | 设置指定通道电压（V，两位小数，如 `VOLT1 12.00`） |
| `CURR{ch} <value>` | W | 设置指定通道限流（A，两位小数，如 `CURR1 1.00`） |

### 4.3 测量

| 命令 | 方向 | 说明 |
| --- |:---:| --- |
| `:MEAS{ch}:VOLT?` | Q | 读取指定通道实际电压（V） |
| `:MEAS{ch}:CURR?` | Q | 读取指定通道实际电流（A） |

---

## 五、注意事项

1. **指令结尾**：TCP 与串口均为 `\n` (LF)。
2. **输出状态判定**：PSW-8027 的 `:OUTP?` 返回 `"1"`；GPP-4323 返回 `"ON"` 或 `"1"`，均判为开。
3. **GPP-4323 串口独占**：串口为独占资源，同一时刻只能有一个进程打开，勿多进程并发访问；共享串口下多通道指令串行发送。
4. **格式差异**：GPP-4323 电压/电流设置输出两位小数；PSW-8027 直接发送数值。
5. **安全顺序**：测试结束先关闭输出（`OUTP 0` / `:OUTP{ch} Off`）再断开连接。
